# Wagoner Johnson Lab website

Source for the lab website at https://wagonerjohnson.mechse.illinois.edu.

- **Editing content:** see [EDITING.md](EDITING.md). All day-to-day edits happen in a web browser.
- **One-time technical setup:** see [SETUP.md](SETUP.md). This takes someone comfortable with GitHub about an afternoon.

Built with [Astro](https://astro.build). It is a static site: the build produces plain HTML files in `dist/`, which the campus cPanel server picks up from GitHub automatically.
